🌟 公开永久留言

📝 如何提交你的留言？

  1. Fork 本项目仓库：github.com/sfghgy249/xiaolu-blog
  2. 在 data/rumors.json 文件末尾按格式添加你的留言条目
  3. 提交 Pull Request，等待管理员审核合并
  4. 合并后GitHub Pages自动部署，刷新页面就能看到你的留言啦！

📋 提交格式模板：

{
  "nickname": "你的昵称（可选，留空填匿名）",
  "date": "2026-07-26",
  "content": "你想说的话，简短一点就好～",
  "tags": ["标签1", "标签2"]
}

⚠️ 审核规则

  • 禁止提交违法违规、色情暴力、政治敏感内容
  • 禁止泄露他人隐私信息（真实姓名、QQ号、手机号、地址等）
  • 禁止人身攻击、引战、恶意言论
  • 广告、推广内容不予通过
  • 管理员保留删除不当内容的权利
